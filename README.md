# 汉藏多科室医疗问答数据集构建项目


本项目构建了覆盖六大临床科室的汉藏双语医疗问答数据集，专门针对藏语等低资源语言在医学问答领域的资源匮乏问题。

## 📋 项目简介

本项目通过多源采集、严格去噪、隐私脱敏与专家双重复核，构建了包含39,274条中藏对齐问答对的高质量医疗数据集。数据集涵盖耳鼻喉科、眼科、内科、神经内科、外科、营养保健科六大临床科室，为汉藏医学问答及多语医学模型研究提供可靠基准。

## 🚀 主要特性

### 数据集特色
- **规模庞大**：39,274条中藏对齐医疗问答对
- **科室全面**：覆盖六大临床科室
- **质量保证**：专家双重复核与多维质量评估
- **隐私保护**：完整的敏感信息脱敏流程

### 技术创新
- **智能科室分类**：基于RoBERTa的深度学习分类器
- **多阶段翻译**：机器初译-专家校准-双重复核的汉藏翻译流程
- **多维评估**：医学准确性、安全性、完整性、语言表达四维评估体系
